# Warehouse Slotting Optimizer

**Zion Warehouse Slotting Optimizer** — SKU placement optimization that cuts pick time, travel distance and congestion.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/warehouse-slotting-optimizer/

## ✨ Features
- **ABC/velocity slotting** — places fast movers within golden-zone reach automatically.
- **Affinity grouping** — co-locates SKUs frequently picked together.
- **Seasonal re-slotting plans** — generates move lists ranked by ROI.
- **Congestion heatmaps** — spots aisle bottlenecks before peak hits.
- **Pick-time simulator** — predicts labor savings before you move a single pallet.
